# Полищук Кирилл, группа 11/1-РПО-26

## Кейс-исследование: Facebook и Cambridge Analytica (2018)

---

### 1. Какие данные собирались и у кого

Собирались личные данные пользователей Facebook: имя, возраст, местонахождение, список друзей, отметки «нравится» (лайки), сообщения в публичных группах. Особенность в том, что данные брались не только у тех, кто установил приложение, но и у их друзей - без какого-либо согласия друзей.

Масштаб: по данным самой Facebook, затронуты данные около 87 миллионов пользователей. Основная часть - граждане США, но пострадали пользователи из десятков стран.

---

### 2. Как данные собирались технически

Александр Коган, исследователь из Кембриджского университета, создал тест-приложение для Facebook под названием «This Is Your Digital Life» - психологический тест-викторина. Около 270-320 тысяч человек прошли тест и дали приложению доступ к своим данным.

До 2015 года Facebook разрешал приложениям читать не только данные установившего пользователя, но и данные всех его друзей через Graph API. Это стандартная функция платформы, задокументированная публично. Коган воспользовался ею легально - но затем передал собранные данные компании Cambridge Analytica, что противоречило условиям использования Facebook (данные можно было использовать только в академических целях).

Cambridge Analytica использовала данные для построения психографических профилей избирателей и таргетированной политической рекламы - в первую очередь для предвыборной кампании Дональда Трампа в 2016 году.

Если смотреть в Network-вкладке браузера того времени: при первом входе в приложение уходил OAuth-запрос к `graph.facebook.com/oauth/authorize` с permissions: `friends_likes, friends_location, friends_relationships`. Сам Graph API возвращал JSON с полями id, name, location, likes каждого друга пользователя. Всё это выглядело как обычный легитимный запрос - никаких скрытых вызовов, потому что Facebook сам давал доступ через официальный API.

---

### 3. Кто получил данные и зачем

Данные получила компания Cambridge Analytica (Великобритания/США), аффилированная с политическим консультантом Стивом Бэнноном и спонсором Робертом Мерсером.

Цель - построить психографические профили избирателей по модели OCEAN (Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism) и показывать людям максимально персонализированную политическую рекламу, которая давила бы именно на их психотип. Применялось в предвыборных кампаниях в США (Трамп, 2016) и в Великобритании (кампания Brexit).

---

### 4. Как это стало известно

В марте 2018 года сразу несколько изданий - The Guardian, The New York Times и Channel 4 News - опубликовали расследование на основе показаний бывшего сотрудника Cambridge Analytica Кристофера Уайли. Уайли передал журналистам внутренние документы компании и подробно описал схему сбора данных.

После публикаций:
- Facebook признал факт передачи данных и заморозил аккаунты Cambridge Analytica на платформе.
- Комиссия по торговле США (FTC) начала расследование.
- Британский регулятор ICO провёл обыски в офисе Cambridge Analytica.
- В США прошли слушания в Сенате, где генеральный директор Facebook Марк Цукерберг давал показания.

---

### 5. Чем закончилось

- Facebook заплатил рекордный на тот момент штраф - $5 млрд по соглашению с FTC (июль 2019). Дополнительно - штраф £500 000 от британского ICO (максимум по действовавшему тогда закону).
- Facebook обязали создать независимый комитет по конфиденциальности на уровне совета директоров и ежеквартально подтверждать соответствие требованиям.
- Cambridge Analytica объявила о банкротстве и прекратила работу в мае 2018 года - ещё до окончания всех расследований.
- Александр Коган не был привлечён к уголовной ответственности: его действия по сбору данных через API не нарушали законодательство на тот момент - только правила платформы.
- Facebook закрыл возможность читать данные друзей через Graph API для сторонних приложений в 2015 году (до публичного скандала), но уже собранные данные у Cambridge Analytica никто не стёр.

## Самоизмерение: сторонние домены на трёх сайтах

Открыл три сайта в режиме инкогнито, вкладка Network - смотрел все домены, не совпадающие с основным.

### Сайт 1 - wildberries.ru

Сторонние домены: `mc.yandex.ru` (Яндекс.Метрика), `pixel.facebook.com` (Facebook Pixel), `cdn.retailrocket.ru` (система рекомендаций), `top-fwz1.mail.ru` (Mail.ru счётчик).

Итого: 4 сторонних трекера.

### Сайт 2 - hh.ru

Сторонние домены: `mc.yandex.ru`, `www.google-analytics.com` (GA4), `pixel.facebook.com`, `an.yandex.ru` (Яндекс.Директ реклама).

Итого: 4 сторонних трекера.

### Сайт 3 - habr.com

Сторонние домены: `mc.yandex.ru`, `www.google-analytics.com`, `connect.facebook.net` (Facebook SDK).

Итого: 3 сторонних трекера.

Вывод. Яндекс.Метрика есть на всех трёх сайтах - это стандарт для русскоязычного интернета. Facebook Pixel тоже встречается часто: он нужен для настройки рекламных аудиторий. Ни один из этих трекеров не выглядит как несанкционированный - на каждом сайте должны быть политика конфиденциальности и согласие пользователя. Отличие кейса Cambridge Analytica в том, что там данные уходили третьей стороне, о которой пользователь даже не знал.

## К презентации (5-7 минут)

1 мин - Вступление. О чём речь: самый громкий скандал с утечкой данных в истории соцсетей. 87 миллионов человек, выборы США 2016, штраф $5 млрд.

2 мин - Как работала схема. Приложение-тест → Graph API → данные друзей. Нарисовать на доске: пользователь ставит приложение → API отдаёт данные 300 его друзей → данные уходят Cambridge Analytica.

1 мин - Зачем. Психографические профили, модель OCEAN, таргетированная политическая реклама. Не продавали товары - влияли на решения на выборах.

1 мин - Как раскрылось. Кристофер Уайли, внутренние документы, The Guardian, слушания в Сенате, Цукерберг давал показания.

1 мин - Итог. $5 млрд штраф, Cambridge Analytica закрылась, Facebook закрыл дыру в API - ещё до скандала, но молча.

1 мин - Связь с нашим курсом. Показать: любой запрос в Network-вкладке, который уходит не на основной домен - это потенциально сторонний сборщик данных. Facebook Pixel на Wildberries делает то же самое, только в рамках закона и с согласия.
