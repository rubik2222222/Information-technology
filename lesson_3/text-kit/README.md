# Text Kit

Набор функций для работы со строками, числами, датами и для проверки данных (почта, телефон, пароль). При запуске программа показывает, как работает каждая функция на примерах.

Нужен Python 3.10 или новее, сторонних библиотек нет.

## Структура

```
text-kit/
├── app/
│   ├── __init__.py
│   ├── main.py              # запуск, примеры данных и вывод
│   ├── utils/
│   │   ├── __init__.py
│   │   ├── text.py          # функции для строк
│   │   └── dates.py         # функции для дат
│   └── services/
│       ├── __init__.py
│       ├── statistics.py    # расчеты по числам
│       └── validation.py    # проверка почты, телефона, пароля
├── tests/
│   ├── test_text.py
│   ├── test_dates.py
│   ├── test_statistics.py
│   └── test_validation.py
├── .gitignore
└── README.md
```

## Как разделил функции

Разделил по темам, в каждом файле одна тема: строки, даты, числа, проверка данных. Имена файлов взял из импортов в тестах.

В utils положил строки и даты, потому что это общие функции и их можно использовать в любом проекте. В services положил расчеты и проверку данных, это уже то, что нужно именно в этом проекте.

Функция is_email использует clean_spaces, поэтому в validation.py добавил импорт из app.utils.text. В main.py остались только константы и функция main, остальное импортируется из модулей.

## Запуск

Из папки text-kit:

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```
