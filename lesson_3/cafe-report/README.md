# Cafe Report

Программа читает заказы кофейни из файла data/orders.csv и выводит отчет: сколько заказов, выручка, средний чек и сколько заработал каждый официант.

Нужен Python 3.10 или новее, сторонних библиотек нет.

## Структура

```
cafe-report/
├── app/                 # код программы
│   ├── __init__.py
│   ├── main.py          # запуск программы
│   ├── services/        # расчеты по заказам и отчет
│   │   ├── __init__.py
│   │   ├── orders.py
│   │   └── report.py
│   └── utils/           # вспомогательные функции (деньги, строки)
│       ├── __init__.py
│       ├── money.py
│       └── text.py
├── data/                # данные
│   └── orders.csv
├── docs/                # описание проекта
│   └── about.md
├── tests/               # тесты
│   ├── test_orders.py
│   └── test_report.py
├── .gitignore
├── requirements.txt
└── README.md
```

Удалил лишние файлы: кеш питона (.pyc), .DS_Store, заметки и старую версию программы. Файл .env остается только у меня на компе, в гит он не попадает (есть в .gitignore).

## Запуск

Из папки cafe-report:

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows можно писать py вместо python, окружение включается так: .\.venv\Scripts\Activate.ps1
